# Drug Review Sentiment Analysis

Text mining project (CRISP-DM) on patient drug reviews — sentiment classification + topic modeling to surface effectiveness and side-effect insights.

## Dataset 
[Drug Review Dataset (Druglib.com)](https://archive.ics.uci.edu/dataset/461/drug+review+dataset+druglib+com)
- UCI Machine Learning Repository. Not included in this repo due to license restrictions 
(non-commercial research use only). Download and place in `data/` before running.
